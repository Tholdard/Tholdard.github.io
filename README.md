# Seth Esparza Portfolio

Static personal portfolio website for GitHub Pages.

## Files

- `index.html` - main website content
- `style.css` - website styling
- `script.js` - small mobile navigation script

## How to publish with GitHub Pages

1. Create a GitHub repository named `Tholdard.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the root of the repository.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. Your portfolio link should be: `https://Tholdard.github.io`

If you use a different repository name, your link will usually be:
`https://Tholdard.github.io/repository-name/`
